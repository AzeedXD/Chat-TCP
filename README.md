This project uses flatlaf, if you dont have it, you need to add it manually:
1.Dowload flatlaf.jar on maven
2.If you use IntelliJ IDEA: 
          1.Open your project
          2.File->Structure
          3.Libraries
          4.Click on +
          5.FInd your flatlaf file and select it
If it still show you an error in flatlaf, you must select it in modules
          1.File->Project Structure
          2.Modules
          3.Dependencies
          4.Click on + ->JARs or Directories
          5.Select your file
          6.After you selected it make sure that scope is set on Compile
